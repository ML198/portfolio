Projects

Research and data science work in biostatistics & bioinformatics

Age Effect Explorer: Interactive Transcriptomics Browser

An interactive R Shiny application for exploring tissue-specific age- and sex-associated gene expression changes across 54 human tissues using GTEx v10 bulk RNA-seq data, applying multivariable linear regression and FDR correction across thousands of genes. Co-first-author publication in Bioinformatics Advances (2026).

R · Shiny · SQL · Linear Regression · FDR Correction

EEG Biomarker Validation in Epilepsy Drug Trials

Analyzed multi-center epilepsy trial data to compare seizure-free survival across treatment arms and evaluate EEG spike activity as a predictive biomarker, using survival analysis, Cox proportional hazards modeling, and diagnostic accuracy metrics in SAS.

SAS · R · Survival Analysis · Cox PH · Biomarker Validation

Urban Wild Bee Resistome Analysis

Built a complete bioinformatics pipeline integrating four ARG databases (CARD, RGI, Resfams, SARG) to identify 1,841 high-confidence antibiotic resistance genes across urban wild bee gut microbiomes, characterizing horizontal gene transfer risk and environmental contamination patterns.

Bioinformatics · Metagenomics · Pipeline Development · Diversity Analysis

Reproducible Health Insurance Data Analysis

Developed an end-to-end reproducible analysis pipeline for a real-world health insurance dataset, demonstrating industry best practices including Docker containerization, Makefile automation, R Markdown reporting, and version control.

R · Docker · Makefile · R Markdown · Reproducible Research

Oncology Biomarker Validation

Engineered a Random Forest classifier achieving greater than 90% AUC for predicting treatment response in oncology patients, using PCA to reduce over 300 clinical and molecular features and supporting weekly clinical team reporting.

Python · R · Random Forest · PCA · Cross-Validation

Environmental Resistance Gene Forecasting

Applied LSTM time series modeling to forecast antibiotic resistance gene prevalence under varying pesticide exposure scenarios, and built an XGBoost classifier (89% accuracy) to predict resistance risk from microbial and land-use features.

Python · LSTM · XGBoost · Time Series · Environmental Health
